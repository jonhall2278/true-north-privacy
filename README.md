# true-north-privacy

The privacy policy for the True North app (iPhone) and tnbrain.com, published with GitHub Pages at
https://jonhall2278.github.io/true-north-privacy/. The app's "Privacy policy" links and App Store Connect point here.

Edit `index.html`, change the "Effective" date at the top, and push to `main`; Pages republishes within a minute or two.
If what's collected or who it's shared with changes, update the App Store Connect "App Privacy" answers to match.
